# Product

## Register

product

## Users

Power users doing LLM-assisted (vibe coding) workflows on small laptop screens. They keep multiple terminals, editors, dev tools, and context panels simultaneously visible on a spatial canvas they pan and zoom like a 2D schematic or circuit board. Not mouse-averse but pointer-aware: they navigate by spatial memory, not hierarchical menus.

## Product Purpose

Cockpit IDE is a floating-panel IDE built around a zoomable/pannable canvas. Every plugin (Monaco editor, terminal, dev panel, file explorer, context viewer) lives as a draggable card on this canvas. The canvas is the product: a spatial schematics-viewer for your active coding session. Success means a developer can lay out their entire LLM-assisted workflow at a glance and navigate it without fighting the UI.

## Brand Personality

Precise. Quiet. Dense. The interface is an instrument panel: information-dense, calibrated, purposeful. Nothing decorative, nothing wasted. Personality comes from craft and restraint, not from visual flair.

## Anti-references

- Generic SaaS dark mode: no neon-on-black, no Dracula palette, no cyan/purple glows
- VS Code sidebar forest: no activity bar, no heavy chrome, no extension marketplace aesthetic
- Electron-app clichés: no translucent sidebar blurs used decoratively, no hero gradients

## Design Principles

1. **Interface recedes** — UI chrome should nearly disappear. Code, output, and terminal are the only things demanding attention.
2. **Spatial instrument logic** — canvas elements are instruments on a panel, not decorative cards. Position and density carry meaning.
3. **Density over decoration** — every visible element earns its place by conveying information. Whitespace serves separation, not aesthetics.
4. **One committed system** — Noir × Art Nouveau × Floating is a coherent design language, not a mood board. Maintain it; don't mix in unrelated patterns.
5. **Quiet contrast** — dark but not generic SaaS. Tinted neutrals, accent used for state only (not decoration), restrained color.
